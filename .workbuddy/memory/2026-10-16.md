# 2026-10-16

## 新增：快捷标的 / 交易方向 的用户自定义配置

需求：在「记一笔」里让用户自行增删改「快捷标的」和「交易方向」的可选项，按用户维度持久化，
处理重复 / 空值 / 超长输入，且不能影响原有表单校验与提交。

### 新增文件
- `src/lib/quickOptions.ts` — 纯函数层（无 React / 无浏览器依赖，前后端共用）：
  常量 `QUICK_OPTION_LIMIT=30`、`SYMBOL_MAX_LEN=24`、`DIRECTION_MAX_LEN=12`、
  `NO_DIRECTION='__none__'`（shadcn Select 不接受空字符串 value）；
  `normalizeQuickOptions()` 统一收敛空值/超长/重复/控制字符（大小写不敏感去重）；
  `validateLabel()` 用于新增时即时校验；localStorage 读写（key `tn.quickOptions.v1`）。
- `src/hooks/useQuickOptions.ts` — 本机缓存 + 云端同步，冲突用**服务端时钟**时间戳比较（避免时钟漂移）；
  云端不可用时降级为本机存储（dirty 标记，下次补推）。
- `src/components/QuickOptionsDialog.tsx` — 编辑器：新增/重命名/上下移/删除/恢复默认，两类共用一套交互。
  父组件只在 open 时挂载，草稿状态每次打开重新初始化（避免 effect 里 setState）。
- `app/api/preferences/route.ts` — GET/PUT，用户维度 = httpOnly cookie `tn_uid`（首次访问服务端生成，1 年有效）。
- `assets/migrations/003_quick_options.sql` — 建 `user_preferences(uid pk, symbols jsonb, directions jsonb, updated_at)`，
  给 `trades` 加 `direction text not null default ''`。

### 关键决策 / 坑
- 用户维度：项目无 Auth，用匿名 uid cookie 实现；接 Supabase Auth 后把 uid 换成 `auth.uid()` + RLS 即可。
  因为 Postgres 侧无法校验 cookie，该表**暂不建议开 RLS**（开了只会让功能不可用），已在迁移脚本注释说明。
- 写 `\u0000` 这类转义到文件时会被 JSON 解析成真实控制字符，改用 `codePointAt` 逐字符过滤规避。
- `react-hooks/refs` lint：不能在 render 期间写 `ref.current`，改成 useCallback 包裹的 `applySyncedAt`。
- 沙箱网络隔离下 `/api/preferences` 返回 500（`fetch failed`），但 cookie 正常下发、前端降级路径可用。

验证：`tsc` EXIT=0、`eslint` EXIT=0（0 warning）、dev 首页 200、`/api/preferences` 正常下发 `tn_uid` cookie。
