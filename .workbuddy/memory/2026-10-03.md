### 踩坑记录

- zod `.catch()` 会让输出类型退化成 `unknown`：`request()` 签名必须用
  `z.ZodType<T, z.ZodTypeDef, unknown>`；schema 默认值写 `.default(x)` 而非 `.optional().default(x)`。
- `next/dynamic` 的 `ssr: false` 不能出现在 Server Component 里 → 抽 `'use client'` 包装组件（DevInspector）。
- Next 16 废弃 `middleware.ts` → `proxy.ts`，导出改成 `export default async function proxy()`。
- ESLint `react-hooks/set-state-in-effect`：effect 里直接 setState 会报错，需按需 disable 或改用 ref/derived。
- `.next` 缓存会残留已删除路由的类型 → 类型报错时先删 `.next` 再跑 `tsc`。
- 沙箱网络隔离，Supabase 请求 ECONNRESET，只能靠类型 + lint + 编译验证，无法跑真实数据。
