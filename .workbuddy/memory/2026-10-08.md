## 新增「盈亏比」统计指标

用户要求：添加盈亏比数据，保留小数点一位。

- **口径**：盈亏比 = 平均每笔盈利 ÷ 平均每笔亏损（绝对值）。
  （备用口径 `profitFactor` = 总盈利/总亏损 也已算好存在 filteredStats 里，当前未展示，
   用户若要切换口径改一行即可。）
- `src/hooks/useTradeStats.ts`：`filteredStats` 新增 `profitRatio` / `profitFactor`。
  无亏损笔数 → Infinity；无盈亏数据 → NaN。两者都由 renderValue 渲染为 '-'。
- `src/components/primitives.tsx`：`ValueFormat` 新增 `'ratio'`，渲染 `n.toFixed(1)`。
- `src/components/StatsPanel.tsx`：筛选结果网格由 3 列改 4 列（净盈亏/交易笔数/胜率/盈亏比），
  下方加口径说明；盈亏比 ≥1 绿色、<1 红色，非有限值不着色。

验证：`tsc` EXIT=0、`eslint` EXIT=0。

### 补充：盈亏比是否区分账户

**区分。** 整条链路都带 accountId：
`page → useTradingData.loadData(accountId) → api.trades.getAll({accountId}) → GET /api/trades → accountScope()`
拉取时就在服务端按账户过滤，useTradeStats 只消费当前账户的 trades，所以盈亏比/胜率/净盈亏
都跟账户选择器联动。统计面板标题 hint 已改为「仅统计当前账户，按开仓日期筛选区间表现」。

   原因：只要存在 babel 配置文件，Next 就永久禁用 SWC，生产构建走 Babel（约 32s）。
2. **recharts 懒加载**：拆出 `src/components/EquityLineChart.tsx`，EquityChart 用
   `next/dynamic` + `open &&` 条件渲染，展开才下载（走势图默认折叠）。
3. **写操作不再全量刷新**：`useTradingData` 新增 `applyTradeSaved/applyTradeDeleted/
   applyFundSaved/applyFundDeleted`，直接用接口返回的「权威记录 + 权威余额」更新本地 state，
   省一次跨境往返。排序用 `insertByDateDesc`（date 降序，同日新记录插最前，与服务端一致）。

### 新指标（都在 useTradeStats，口径写进代码注释）

- **最大回撤**：遍历资金曲线，`peak` 为当时历史峰值，取 `(peak - value)/peak` 最大值；
  比率分母是**当时的峰值**而非全局峰值（标准定义）。资金曲线 ≤0 不计。
  `percent` 存负值用于展示（-12.3%），`amount` 为正。已知特性：出金拉低曲线会被计为回撤。
- **连胜连亏**：按 date + openTime **升序**遍历已平仓交易；**打平（pl=0）视为打断**
  （既不续连胜也不续连亏）。返回 current{type,length} / maxWin / maxLoss。
- **期望值**：胜率×平均盈利 − 亏损率×平均亏损（数学上等价 净盈亏/笔数，
  展开式更能反映系统特性）。
- primitives 新增 `percent1`（一位小数百分比）与 `text` 格式，Stat 新增 `hint` 副标题。
