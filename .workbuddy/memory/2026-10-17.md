# 2026-10-17

## 新增：交易复盘字段（执行度 / 纪律标签 / 情绪状态）+ 列表布局修复

### 数据模型
- 新增 `src/lib/review.ts`（纯函数层，固定枚举，不做用户自定义 —— 改名会让历史统计无法横向比较）：
  - `executionScore` 0–5，0 = 未评分
  - `disciplineTags` 10 项多选（遵守计划/仓位合理/追高/FOMO 入场/提前止损/拖延止损/
    频繁交易/仓位过大/逆势加仓/报复性交易），`good` 标记仅用于视觉强弱，**不参与涨跌配色**
  - `emotion` 8 项单选（冷静/自信/焦虑/犹豫/贪婪/恐惧/急躁/懊悔），空串 = 未记录
  - 宽松解析三件套 `clampExecutionScore` / `parseDisciplineTags` / `parseEmotion`，缺列时回落到「未填写」
- `src/lib/schema.ts`：`tradeSchema`、`parseTrade`、`createTradeSchema` 全部接入（update 走 `partial()` 自动继承）
- `assets/migrations/004_trade_review.sql`：`execution_score smallint`（带 0–5 check 约束）、
  `discipline_tags text[]`、`emotion text`

### 布局
- `TradeTable` 改 `table-fixed min-w-[1020px]` + 每个单元格 `<span className="block truncate">` + 行 `h-12`，
  长策略/长备注不再撑开整行；新增「复盘」列（执行度点阵 + 情绪 + 标签，最多 1 个 +N）
- 操作按钮改为 hover 浮出：`sm:opacity-0 sm:group-hover:opacity-100 sm:focus-within:opacity-100`
  （`sm:` 前缀保证触屏无 hover 时按钮常驻，不丢 CRUD）
- `TradeDialog` 增加 `view` 模式：`DialogMode = 'create'|'edit'|'view'|null`，
  详情只读渲染 + footer「编辑」按钮切到 edit；`mode={mode ?? 'create'}`
- `src/components/TradeReview.tsx` 抽出 `ExecutionDots/EmotionChip/DisciplineChips/ReviewPreview/
  ReviewEditor/ReviewDetail`，列表预览、详情、编辑表单三处复用同一组件，口径与文案一致

### API 向后兼容（重要）
- `app/api/trades/route.ts` 的缺列降级从「只处理 direction」升级为通用机制：
  `OPTIONAL_COLUMNS = ['direction','execution_score','discipline_tags','emotion']` + `missingColumnOf()`
  + `writeTrade()` 逐个剔除缺列重试。PostgREST 缺列报错码是 **PGRST204**（`Could not find the 'x' column
  ... in the schema cache`），不是 42703，所以判定条件要同时覆盖 `could not find` / `schema cache`。
  未跑 003/004 迁移时**仍能正常记账**，只是新字段存不下。
