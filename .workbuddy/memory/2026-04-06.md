# 2026-04-06

## 币安期权交易历史模块开发

### 新建文件
- `assets/binance_options_trades.sql` — 建表SQL，含索引和触发器
- `src/lib/binance.ts` — 币安 eapi `/eapi/v1/userTrades` 对接，HMAC-SHA256签名，支持自动分页
- `src/lib/db.ts` — pg Pool 单例，兼容 Vercel Postgres / Supabase 直连
- `app/api/options-trades/route.ts` — GET（列表+统计+分页）/ PATCH（更新备注）
- `app/api/options-trades/sync/route.ts` — POST 同步，upsert时保留用户备注
- `app/options/page.tsx` — 前端页面（统计卡片、一键同步、筛选、行内编辑备注）
- `.env.example` — 环境变量示例

### 修改文件
- `app/page.tsx` — 顶部添加「币安期权历史」入口按钮（蓝色），链接到 /options

### 架构决策
- 数据库用 `pg` 库（已在 package.json），不新增依赖
- 以 `binance_options_trades` 表存储，与原有 Supabase trades 表完全独立
- Upsert 时故意不覆盖 remark 字段，保护用户备注
- API Key 仅在服务端读取，前端无法获取

### 修复（逻辑检查后）
- 主键由 orderId 改为 tradeId（一个订单可能对应多笔成交，tradeId 才是真正唯一键）
- ParsedOptionTrade 接口新增 orderId 字段，单独存储 order_id 列
- 建表SQL新增 order_id 列和对应索引
- binance.ts 中 id 映射从 raw.orderId 改为 raw.tradeId
